# Responsive layout checklist

## Purpose

Review meal cards and shopping list at 320px, 375px, 430px, 768px and 1280px, large text, keyboard focus, touch targets, and print readability.

## Review procedure

1. Verify current production behavior before making changes.
2. Record browser, device, date and test outcomes.
3. Document actual failures and fixes in an issue or pull request.
4. Check all public content for personal information and secrets.
5. Confirm GitHub Pages deployment after merging.

This is a review guide, not evidence that all checks have passed.
