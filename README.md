# 一周营养食谱 · 家庭餐桌

一个部署在 GitHub Pages 的静态家庭食谱网站，包含一周三餐安排与买菜清单。

## 访问与技术

- 站点：<https://food.laoxu.org/>
- 技术：HTML、CSS、JavaScript；无需后端服务器或数据库。
- 首页入口：`index.html`。
- 食谱维护与食品安全检查：[`docs/recipe-maintenance-guide.md`](docs/recipe-maintenance-guide.md)。

## 维护流程

1. 在独立分支编辑食谱或界面，避免直接覆盖线上版本。
2. 对照页面实际数据检查一周菜单、食材清单及不同模式。
3. 用手机和桌面浏览器测试切换、排版和勾选功能。
4. 检查外链是否有效；不要将未验证的视频播放量描述为事实。
5. 通过 Pull Request 合并，并检查 GitHub Pages 部署状态。

## 隐私与安全

此仓库为公开网站。不要提交家庭成员姓名、具体住址、医疗记录、账号凭据或内部工作资料。食谱属于一般信息，特殊饮食需求请遵循专业医疗建议。
